# Typizer для 1С:Предприятия 8.3

Распознавание документов в 1С: отправили скан или PDF счёта, УПД, акта — получили данные по вашей схеме
структурами 1С, с проверкой ИНН, КПП, БИК, расчётного счёта и суммы строк. Сервис —
[typizer.ru](https://typizer.ru), данные и модели размещены в России (152-ФЗ).

Здесь два проекта с открытым кодом под лицензией MIT:

| Папка | Что это | Кому |
|---|---|---|
| [`sdk/`](sdk/) | **SDK**: два общих модуля без БСП для любой конфигурации 8.3.17+ — БП, УТ, КА, ERP, доработанной или самописной | Разработчикам и франчайзи, которые встраивают распознавание в свою конфигурацию |
| [`examples/bp/`](examples/bp/) | **Пример** на SDK — расширение для «1С:Бухгалтерии предприятия» 3.0: пачка сканов в фоне → поступления, счета поставщиков, счета-фактуры | Тем, кто хочет посмотреть законченную интеграцию или взять её за основу |

Готовые файлы — в [релизах](https://github.com/typizer/typizer-1c/releases): `typizer-1c-sdk.cfe` (SDK расширением),
`typizer-1c-sdk.zip` (тексты модулей), `typizer-1c-bp-example.cfe` (пример для «Бухгалтерии»).

## Быстрый старт

```bsl
// Серверный код. КлючAPI — из вашего хранилища (константа, БСП «Безопасное хранилище»).
Подключение = ТипизаторAPI.НовоеПодключение(КлючAPI);
Параметры = ТипизаторAPI.ПараметрыПрогона();
Параметры.Схема = "{""type"":""object"",""properties"":{""seller_inn"":{""type"":""string""},""total"":{""type"":""number""}}}";

Результат = ТипизаторAPI.РаспознатьФайл(Подключение, ДвоичныеДанные, "Счёт №15.pdf", Параметры);
Если Не Результат.Успех Тогда
	ВызватьИсключение Результат.Ошибка.Текст;
КонецЕсли;
ИННПродавца = ТипизаторAPIКлиентСервер.ЗначениеПоля(Результат.Данные, "seller_inn");
Сумма = ТипизаторAPIКлиентСервер.ЗначениеПоля(Результат.Данные, "total");
```

1. Зарегистрируйтесь на [my.typizer.ru](https://my.typizer.ru) — 100 страниц бесплатно, ещё 200 за ИНН организации, без карты.
2. Создайте ключ API.
3. Подключите `typizer-1c-sdk.cfe` и **снимите флажок «Безопасный режим»** у расширения — иначе 1С запрещает HTTP-запросы.

Подробно: [sdk/README.md](sdk/README.md) и [docs.typizer.ru/how-to/1c-sdk](https://docs.typizer.ru/how-to/1c-sdk).

## Пример для «Бухгалтерии»

Расширение из `examples/bp/` показывает, как строить интеграцию на SDK: распознавание пачкой в фоне, поиск
контрагента по ИНН/КПП, договор, номенклатура, НДС, поступление, счёт поставщика, счёт-фактура. Берите его за
основу и дорабатывайте под свою конфигурацию.

## Можно ли на этом зарабатывать

Да. Лицензия MIT: используйте, меняйте, встраивайте в свои доработки и продавайте их клиентам. Сохраните только
текст лицензии в копиях. Пишете решение на SDK — расскажите нам, добавим ссылку на странице
[typizer.ru/integrations/1c](https://typizer.ru/integrations/1c/).
